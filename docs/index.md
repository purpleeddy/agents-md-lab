# agents-md-lab

Evidence-graded linter and experiment harness for AGENTS.md / CLAUDE.md context files.

> Not affiliated with the AGENTS.md specification or the Agentic AI Foundation.

**Core.** Lint context files with deterministic, source-cited checks. Test contested rules with pre-registered behavioral experiments. Recommend a file backed by evidence rather than taste.

Every check carries an evidence grade: `G` (vendor guidance or literature only), `E+` (an experiment here supports it), `E-` (an experiment here does not). The score you will see is guideline conformance, not quality, and no page ranks files.
